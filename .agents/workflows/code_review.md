# Instructions
當使用者觸發此指令時，請嚴格按照以下步驟執行：

1. **讀取規範文件**：請優先使用你的檔案讀取能力，讀取專案路徑下的 `ImTK\docs\Project\DevelopmentWrapUp.md` 文件。
2. **理解審查標準**：分析該文件中的開發規範、注意事項以及 Code Review 的具體步驟與檢查清單 (Checklist)。
3. **執行程式碼審查**：
   - 根據使用者提供的程式碼或當前的 Git Diff（修改內容），套用上述文件中的標準進行檢查。
   - 檢查是否符合架構規範、命名慣例、效能要求及錯誤處理等原則。
4. **產出審查報告**：
   - 如果發現不符合 `DevelopmentWrapUp.md` 規範的地方，請具體指出並提供修改建議。
   - 如果程式碼表現良好，請給予確認並說明其符合哪些規範。
   - 報告格式請保持清晰易讀（使用條列式或表格）。
