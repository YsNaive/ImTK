# Chassis 設計考量與工程妥協 (Design Notes)

本文件記錄了 Chassis 底層元件為了克服物理環境（如靜摩擦力、轉向物理極限）所作的特殊設計。

## 1. 克服靜摩擦力 (Minimum Drive Voltage)

**設計選擇**：在底層動力系統或是控制器中，必須存在將微小 PID 輸出強制拉抬到特定閾值（如 `MIN_DRIVE_VOLTAGE`）的邏輯。
**原因**：機器人在靜止時存在靜摩擦力。當 PID 算出的電壓極小（例如快到目標時，或是誤差極小時），馬達會發出高頻聲音但無法轉動，導致無法真正到達目標。
**未來演進**：在引入 PIDF (包含 Feedforward 前饋) 的控制器後，此暴力補償會被 $K_s$ (靜摩擦常數) 給優雅地取代。

## 2. 轉向優先邏輯 (Steering Priority in Arcade Drive)

**設計選擇**：當系統同時需要前進與轉向，且總輸出電壓超過馬達最大電壓 $V_{max}$ 時，必須**優先保證轉向能力，並縮減前進能力**。
**原因**：如果同時截斷前進與轉向分量，機器人會偏離預期軌跡。保證轉向能讓機器人即使變慢，也能維持正確的朝向。

**數學拆解實作**：
1. 從左右輪電壓 $(V_L, V_R)$ 中，拆解出「前進分量」($Drive$) 與「轉向分量」($Turn$)。
2. **轉向鉗制**：將 $Turn$ 截斷至 $[-V_{max}, V_{max}]$。
3. **剩餘空間計算**：$MaxDrive = V_{max} - |Turn|$。
4. **前進鉗制**：將 $Drive$ 截斷至 $[-MaxDrive, MaxDrive]$。
5. **重新組合**：$V_L' = Drive' + Turn'$, $V_R' = Drive' - Turn'$。
